# 🎙️ Audio Studio

A free, browser-based audio converter and voice effects tool — no uploads, no sign-up, no server.

🔗 **Live site:** https://github.com/khananas7109-hue/Audiostudio.com.git

---

## ✨ Features

- **Format conversion** — WAV, OGG and more
- **Pitch control** — make voices thick/deep or thin/high (±12 semitones)
- **5-band EQ** — Bass, Low Mid, Mid, High Mid, Treble
- **Noise Gate** — cuts background hiss between words
- **Compressor** — evens out loud and quiet differences
- **High-pass filter** — removes low rumble and AC hum
- **Low-pass filter** — removes high-frequency hiss
- **Reverb & Volume boost**
- **Speed control**
- **Stereo → Mono** conversion
- **Live frequency visualizer** during preview
- **Quick Presets** — Deep Voice, Thin Voice, Radio, Warm, Telephone

---

## 🚀 How to Use

1. Drop or upload any audio file (MP3, MP4, WAV, AAC, OGG, FLAC, WEBM…)
2. Adjust tone, pitch, EQ and noise settings
3. Hit **▶ Preview** to hear changes in real time
4. Hit **⬇ Export** to download the processed file

---

## 🔒 Privacy

All processing happens **100% in your browser** using the Web Audio API. Your files are never uploaded to any server.

---

## 🛠️ Tech Stack

- Vanilla HTML, CSS, JavaScript
- Web Audio API (OfflineAudioContext, BiquadFilterNode, DynamicsCompressorNode)
- MediaRecorder API for OGG encoding
